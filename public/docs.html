Documentación Valorant API

Bienvenido a la documentación oficial de LosPerris Valorant API. Integra datos de rangos, historial de partidas y estadísticas detalladas en tus aplicaciones o bots de chat (Nightbot, StreamElements).

API STATUS: Comprobar estado del servicio

Obtener Rango (MMR)

Devuelve el rango actual, ELO y puntuación de un jugador. Ideal para comandos !rank.

GET /api/valorant/rank/:region/:name/:tag

Parámetros

Parámetro Tipo Descripción
region String na, eu, ap, kr, latam, br
name String Riot ID del jugador
tag String Tagline del jugador
type Number (Opcional) 1: Solo Rango, 2: +Puntos, 3: +ELO

Ejemplos de Uso

curl -X GET "https://losperris.site/api/valorant/rank/na/PonssLoveless/8882"
fetch("https://losperris.site/api/valorant/rank/na/PonssLoveless/8882")
  .then(res => res.json())
  .then(data => console.log(data));
import requests
res = requests.get("https://losperris.site/api/valorant/rank/na/PonssLoveless/8882")
print(res.json())

Copia esto en tu Nightbot o StreamElements:

$(urlfetch https://losperris.site/api/valorant/rank/na/PonssLoveless/8882?format=text)

Respuesta JSON

{ "status": 200, "data": { "current_tier_patched": "Gold 1", "ranking_in_tier": 50, "mmr_change_to_last_game": 15, "elo": 1250 } }

Última Partida

Obtiene estadísticas detalladas de la última partida competitiva jugada.

GET /api/valorant/match/last/:region/:name/:tag 
curl -X GET "https://losperris.site/api/valorant/match/last/na/PonssLoveless/8882"
$(urlfetch https://losperris.site/api/valorant/match/last/na/PonssLoveless/8882?format=text)

Respuesta JSON

{ "status": 200, "data": { "map": "Ascent", "mode": "Competitive", "stats": { "character": "Jett", "kills": 24, "deaths": 12, "assists": 5 }, "won": true } }

Historial (Gráfico)

Devuelve un array con los últimos cambios de MMR para generar gráficos.

GET /api/valorant/history/:region/:name/:tag 
fetch("https://losperris.site/api/valorant/history/na/PonssLoveless/8882")
  .then(res => res.json())
  .then(data => console.log(data));

Resumen de Perfil

Endpoint "Todo en Uno". Devuelve cuenta, rango, última partida e historial en una sola llamada.

GET /api/valorant/summary/:region/:name/:tag
{ "status": 200, "data": { "account": { ... }, "rank": { ... }, "match": { ... } } }

Status Check

Comprueba la salud de la API.

GET /api/valorant/status

Consulta la página visual de estado aquí: Status Dashboard →

Códigos de Error

Código Significado Descripción
400 Bad Request Faltan parámetros o la región es inválida.
404 Not Found El jugador no existe o perfil privado.
500 Server Error Error del servidor o de Riot API.
