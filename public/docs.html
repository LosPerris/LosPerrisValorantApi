API DOCS

Documentación oficial de la API de Valorant

Introducción

Bienvenido a la documentación de LosPerris Valorant API. Aquí encontrarás todos los endpoints disponibles para obtener información de jugadores, rangos y partidas. Todos los endpoints soportan respuestas en formato JSON (por defecto) y texto plano (ideal para bots).

GET /rank

Obtiene el rango actual, ELO y puntuación de un jugador.

/api/valorant/rank/:region/:name/:tag

Parámetros

Nombre Ubicación Descripción
region Path Región (na, eu, ap, kr, latam, br)
name Path Nombre de usuario de Riot
tag Path Tag de Riot (sin el #)
format Query json (default) o text
lang Query en (default) o es
type Query Estilo de respuesta (1, 2, 3)

Tipos de Respuesta (Format Types)

Estos tipos determinan qué tanta información devuelve el bot cuando format=text (útil para Nightbot).

Tipo Ejemplo de Salida (Rank)
1 (Simple) "Actualmente estoy en Ascendente 2"
2 (Detallado) "Actualmente estoy en Ascendente 2 con 50 puntos"
3 (Completo) "Actualmente estoy en Ascendente 2 con 50 puntos, mi mmr es de 1250"

Ejemplo de Solicitud

# JSON (Default)
curl -X GET "https://losperris.site/api/valorant/rank/na/PonssLoveless/8882"

# Texto Plano (Bots)
curl -X GET "https://losperris.site/api/valorant/rank/na/PonssLoveless/8882?format=text"

# Texto en Español
curl -X GET "https://losperris.site/api/valorant/rank/na/PonssLoveless/8882?format=text&lang=es"
// JSON
fetch("https://losperris.site/api/valorant/rank/na/PonssLoveless/8882")
  .then(res => res.json()).then(data => console.log(data));

// Texto
fetch("https://losperris.site/api/valorant/rank/na/PonssLoveless/8882?format=text")
  .then(res => res.text()).then(text => console.log(text));
import requests

# JSON
print(requests.get("https://losperris.site/api/valorant/rank/na/PonssLoveless/8882").json())

# Texto
print(requests.get("https://losperris.site/api/valorant/rank/na/PonssLoveless/8882", params={"format": "text"}).text)

💡 ¿Quieres personalizarlo fácil?
Usa nuestro Generador de Comandos en el inicio para elegir idioma, formato y plataforma visualmente.

# Nightbot / StreamElements / Fossabot

GET /match

Devuelve los detalles de la última partida competitiva.

/api/valorant/match/last/:region/:name/:tag

Parámetros

Nombre Ubicación Descripción
region Path Región del servidor
name Path Nombre de usuario
tag Path Tag del usuario
format Query json (default) o text
lang Query en (default) o es
type Query Estilo de respuesta (1, 2, 3)

Tipos de Respuesta (Format Types)

Igual que en Rank, define el nivel de detalle para format=text.

Tipo Ejemplo de Salida (Match)
1 (Simple) "... gané 15 puntos"
2 (Detallado) "... gané 15 puntos, mi KDA fue 18/12/5"
3 (Completo) "... gané 15 puntos (18/12/5), HS: 25%"

Ejemplo de Solicitud

# JSON (Default)
curl -X GET "https://losperris.site/api/valorant/match/last/na/PonssLoveless/8882"

# Texto Plano
curl -X GET "https://losperris.site/api/valorant/match/last/na/PonssLoveless/8882?format=text"

# Texto en Español
curl -X GET "https://losperris.site/api/valorant/match/last/na/PonssLoveless/8882?format=text&lang=es"
// JSON
fetch("https://losperris.site/api/valorant/match/last/na/PonssLoveless/8882")
  .then(res => res.json()).then(data => console.log(data));

// Texto
fetch("https://losperris.site/api/valorant/match/last/na/PonssLoveless/8882?format=text")
  .then(res => res.text()).then(text => console.log(text));
import requests

# JSON
print(requests.get("https://losperris.site/api/valorant/match/last/na/PonssLoveless/8882").json())

# Texto
print(requests.get("https://losperris.site/api/valorant/match/last/na/PonssLoveless/8882", params={"format": "text"}).text)
{ "data": { "map": "Ascent", "mode": "Competitive", "score": "13-10", "result": "Win", "kda": "18/12/5" } } 
Ascent - Competitive - Win 13-10 - KDA: 18/12/5

GET /history

Obtiene el historial de las últimas 5 partidas competitivas.

/api/valorant/history/:region/:name/:tag

Parámetros

Nombre Ubicación Descripción
region Path Región
name Path Nombre
tag Path Tag

Ejemplo de Solicitud

curl -X GET "https://losperris.site/api/valorant/history/na/PonssLoveless/8882"
fetch("https://losperris.site/api/valorant/history/na/PonssLoveless/8882")
  .then(res => res.json())
  .then(data => console.log(data));
import requests
print(requests.get("https://losperris.site/api/valorant/history/na/PonssLoveless/8882").json())

Respuesta de Ejemplo

{ "status": 200, "data": [ { "map": "Haven", "score": "13-11", "result": "Win", "kda": "22/15/8" }, { "map": "Bind", "score": "5-13", "result": "Loss", "kda": "10/18/4" } ] }

GET /summary

Resumen completo del perfil (Account, Rank, Match, History).

/api/valorant/summary/:region/:name/:tag

Ejemplo de Solicitud

curl -X GET "https://losperris.site/api/valorant/summary/na/PonssLoveless/8882"
fetch("https://losperris.site/api/valorant/summary/na/PonssLoveless/8882")
  .then(res => res.json())
  .then(data => console.log(data));
import requests
print(requests.get("https://losperris.site/api/valorant/summary/na/PonssLoveless/8882").json())

Respuesta de Ejemplo

{ "account": { "name": "PonssLoveless" }, "rank": { "rank": "Ascendente 2" }, "match": { "map": "Ascent", "result": "Win" }, "history": [ ... ]

INFO Manejo de Errores

Códigos de estado HTTP comunes que devuelve la API.

Código Significado Descripción
200 OK La solicitud fue exitosa.
400 Bad Request Faltan parámetros o la región es inválida.
404 Not Found El jugador (Name/Tag) no existe o tiene el perfil privado.
429 Rate Limit Has excedido el límite de solicitudes. Espera unos segundos.
500 Server Error Error interno o problema de conexión con Riot Games.
